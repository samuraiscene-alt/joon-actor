# JOON ACTOR

배우 대본 리딩 및 AI 상대역 연습 앱 (개발 중)

## 진행 상태
- v0.1.0: 49페이지 스캔 대본 OCR 검토용 프로토타입이 로컬 ZIP으로 준비됨
- GitHub 저장소 초기화 단계: **이 저장소는 아직 웹앱 배포 완료 상태가 아님**
- OCR 결과는 자동 인식 초안으로 원문과 대조가 필요함
- 마이크 대사 종료 판정 / AI 상대역 음성 기능은 아직 미구현

## 저작권·개인정보 보호
- 테스트용 원본 대본 PDF, 페이지 이미지, OCR 전체 텍스트는 외부 공개 배포하지 않음
- 대본은 이용자가 직접 앱에서 로컬로 불러와 보관하도록 설계할 예정
- 공개 사이트에 원본 대본이나 AI API 키를 절대 포함하지 말 것

## 앱 아이콘
사용자가 제공한 원본 아이콘을 변경 없이 적용할 것.
